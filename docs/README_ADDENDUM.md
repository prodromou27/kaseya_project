# Add VSA-only Phase 1 requirements to your EXISTING project

This package is an **add-on**, not a new project or replacement for your original documentation.

1. Save your existing work in Git and inspect `git status`.
2. Copy this package's `docs/` into the **existing repository's** `docs/` directory.
3. Copy `CLAUDE_CONTINUE_EXISTING_PROJECT.md` into the repository root.
4. Do **not** overwrite the existing `AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/TASKS.md`, or any source code, migrations or database.
5. Open Claude Code **inside that original repository** and provide the content of `CLAUDE_CONTINUE_EXISTING_PROJECT.md`.

The uploaded original package included 17 Markdown specification files, but did not include the current source repository. Existing code progress must be established by inspecting that repository; unchecked checkboxes from an old ZIP are not reliable progress evidence.

For **this phase**, VSA X is the only vendor. IT Glue, Autotask, Tenable and MCP remain later phases. The original read-only restriction remains in effect; the device group-move capability can be prepared behind a disabled-by-default flag, but cannot perform live writes without separate approval.
